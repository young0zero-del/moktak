💡 반응형 최적화 기능

  • 자동 디바이스 감지: 화면 크기와 성능에 맞춰 자동 최적화
  • 파티클 수 조절: 기기 성능에 따라 파티클(눈/낙엽) 개수 자동 조정
  • 렌더링 품질: 안티앨리어싱, 픽셀비율 등 자동 설정
  • 터치 영역 확대: 모바일에서 버튼 및 슬라이더 터치 영역 44px 이상
  • 가로 모드 지원: 가로 화면에서도 UI 요소 최적화
  • 동적 레이아웃: 화면 회전/크기 변경 시 자동 재조정
  • 폰트 크기 조절: 각 디바이스 크기에 맞는 가독성 최적화
  • 저전력 모드: 소형 기기에서 배터리 효율 우선
