# 🪵 목탁 (Moktak)

웹에서 체험하는 3D 목탁 명상 앱

## ✨ 주요 기능

### 🎵 실제 목탁 음원
- 자연스러운 타격음 (0.8초, 500ms 페이드아웃)
- 음량 조절 및 음소거 기능

### 🎨 계절별 테마
- **봄** 🌸: 분홍빛 새벽, 맑은 하늘, 연한 초록
- **여름** 🌿: 따뜻한 오렌지, 진한 하늘색, 밝은 햇살
- **가을** 🍂: 단풍빛, 베이지 톤 + **낙엽 효과**
- **겨울** ❄️: 눈 덮인 풍경 + **눈 내리는 효과**

### ⏰ 시간대별 분위기
- **새벽** 🌅: 부드러운 조명
- **낮** ☀️: 밝은 분위기
- **밤** 🌙: 차분한 분위기

### 💬 타격 문구
타격할 때마다 랜덤 문구 표시 (연속 중복 방지):
- 공덕 +1, 평온 +1, 자비 +1, 번뇌 −1, 참음 +1, 감사 +1, 친절 +1, 나눔 +1, 지혜 +1

### 🎵 배경 음악
- 절 소리 (불경)
- 자연 소리 (새소리)
- 빗소리

### 🎨 목탁 색상 커스터마이징
- 4가지 프리셋: 기본, 밝은 나무, 어두운 나무, 붉은 나무
- 컬러 피커로 자유로운 색상 선택

## 🎮 사용 방법

### PC
- **클릭** 또는 **스페이스바**: 목탁 타격
- 하단 컨트롤로 설정 조정

### 모바일
- **터치**: 목탁 타격
- 반응형 UI 지원

## 🛠️ 기술 스택

- **Three.js**: 3D 렌더링
- **Web Audio API**: 오디오 재생
- **Vanilla JavaScript**: 프레임워크 없이 구현
- **HTML5 Canvas**: 고성능 렌더링

## 📦 로컬 실행

```bash
# 간단한 HTTP 서버 실행
python3 -m http.server 8000

# 브라우저에서 접속
# http://localhost:8000/moktak-final.html
```

## 🌐 배포

Vercel, Netlify, Cloudflare Pages 등에 정적 사이트로 배포 가능

## ⚙️ 설정 저장

- 타격 횟수
- 타격 문구 표시 여부

위 설정은 브라우저의 localStorage에 저장되어 재방문 시에도 유지됩니다.

## 🎯 접근성

- 키보드 탐색 지원
- 스크린 리더 호환
- `prefers-reduced-motion` 지원: 움직임 줄이기 설정 시 애니메이션 감소

## 📱 반응형

- 모바일 최적화
- 데스크톱/태블릿 지원
- 다양한 화면 크기 대응

## 🔊 오디오 파일

프로젝트에 포함된 오디오:
- `목탁-최종.wav`: 목탁 타격음
- `불경.mp3`: 절 소리 배경음
- `새소리.mp3`: 자연 소리 배경음
- `빗소리.mp3`: 빗소리 배경음
