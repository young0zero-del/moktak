# 🍔 음식 메뉴 블라인드 게임

30초 안에 음식 메뉴의 브랜드와 이름을 맞추는 퀴즈 게임!

## 🎮 게임 방법

1. 게임 시작 버튼 클릭
2. 블라인드 처리된 음식 이미지 보기
3. 30초 안에 4개 보기 중 정답 선택
4. 15개 문제를 모두 풀고 랭킹 확인!

## 🏆 랭킹 시스템

- **1등 (100%)**: 👑 완전 기특! 
- **2-3등 (60-99%)**: 🥈🥉 좋은 결과!
- **4등 (40-59%)**: 😊 괜찮아요
- **꼴찌 (0-39%)**: 🪓 단두대...
